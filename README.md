# MagicFridgeAI
Uma geladeira alimentada por uma IA que sugere receitas de acordo com os ingredientes presentes no banco de dados


## Funcionalidades
- CRUD básico de Itens Alimenticios (CRIAR, BUSCAR POR ID, LISTAR TODOS, ALTERAR E DELETAR)
- Integração com API do GEMINI
- Gera receitas de acordo com itens presentes no banco de dados

## Tecnologias
-  Java
- Spring Boot
- Spring Data JPA
- Hibernate
- H2 Database
- Maven
- WebFlux
- WebClient
- Programação reativa
- Thymeleaf
- Flyway
- DTO
